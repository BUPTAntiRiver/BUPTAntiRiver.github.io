Terminal is an environment that shows the textual input and output, it captures your key-strokes, displays text and draws the visual interface. We have Windows Terminal, GNOME Terminal, Ghostty, etc.

While shell is actually a program runs on the terminal, it is the shell that inteprets your commands like `ls -la` and communicates with the operating system. We have bash, zsh, fish, powershell, etc.

So changing the terminal affects how your window looks, and changing the shell affects the command rules, syntax and behaviors of your window.

Also there are a lot of background programs that can run without a terminal, this tells us the difference between terminal and shell too.

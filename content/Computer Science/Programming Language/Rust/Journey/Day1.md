Rustup 是 Rust 的安装器以及版本管理工具，可以用 `rustup update` 来检查更新。

_Cargo_ 是 Rust 的编译工具以及包管理器。他可以做很多工作：

- `cargo build` 编译项目
- `cargo run` 运行项目
- `cargo test` 测试项目
- `cargo doc` 生成项目文档（！？强强？！）
- `cargo publish` 发布一个库到 crates.io

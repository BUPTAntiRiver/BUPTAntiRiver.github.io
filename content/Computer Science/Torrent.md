# What is Torrent?

## Concept

Torrent is actually a file format, we call it torrent file. A torrent file is normally name with the extension `.torrent`. It works in the **_BitTorrent_** file distribution system, a torrent file can also be called as meta-info file, since it contains metadata about files and folders to be distributed and usually also a list of the network distribution of **_trackers_**, which are computers that help participants in the system find each other and form efficient distribution groups and _swarms_.

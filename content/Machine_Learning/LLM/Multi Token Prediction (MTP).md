Starting to work on MTP, let's read the first paper introduces the idea of MTP.

# What?

MTP is literally predicting the multiple future tokens at once.

# Why?

MTP has better sample efficiency than traditional next token prediction, also large language model monitors human thinking mode with next token prediction but that seems to be inaccurate, nobody thinks with a single word bumping from their mind. Next token prediction is like focusing on local pattern and overlooks "hard" decisions.

MTP not only improves inference speed but also enhances performance.
